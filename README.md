# Nara's Colour Quest — Blue Snake Studios Junior

A kid-safe Baby B$S colouring-book arcade with eight playable browser games and one tiny music beat maker app.

## What is inside

- **Creature Match** — memory card game using creature art.
- **Dino Dash** — Gameasaurus Rex runner.
- **Hidden Jungle Friends** — hidden object game on the jungle colouring page.
- **Catchemall Cat** — couch-cat catching game.
- **Snake Trail Colour Quest** — soft classic snake game.
- **Feather Catcher** — calm feather catching game.
- **Colour Lab** — SVG colouring tool with download.
- **Rex Rhythm** — tap rhythm game with Roar Meter.
- **Beat Maker Lab** — Web Audio step sequencer with creature sounds and effect knobs.

## Open locally

Open `index.html` in a browser.

No build step is required. It is plain HTML, CSS and JavaScript.

## Suggested deployment

Works as a static site on GitHub Pages, Vercel, Netlify or any simple static host.

## Safety rules

- No login.
- No comments.
- No school details.
- No public contact form for the child.
- Kid identity stays as nickname / studio character world.
- Dad / Blue Snake Studios controls all uploads.

## Design rule

Adult B$S = dark myth machine.
Baby B$S = colouring-book arcade, softer, rounder, brighter, creature-safe.

Printable, playable, soft, weird, safe.
